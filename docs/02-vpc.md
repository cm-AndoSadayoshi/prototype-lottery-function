# バリュー・プロポジション・キャンバス（VPC）- グロースパック for LINE 抽選機能

## 概要

ユーザーの「痛み」と解決策をマッチングさせ、プロダクトの価値提案を明確化する。

---

## 顧客プロファイル（Customer Profile）

### Customer Jobs（達成したいタスク）

| # | ジョブ | 種類 |
|---|-------|------|
| 1 | LINEアカウントのエンゲージメントを向上させる | 機能的ジョブ |
| 2 | 低コスト・短期間でキャンペーンを実施する | 機能的ジョブ |
| 3 | キャンペーン参加者データを活用して追客する | 機能的ジョブ |
| 4 | 競合他社との差別化を図る | 社会的ジョブ |
| 5 | 上長にキャンペーン成果を報告できる | 感情的ジョブ |

### Pains（痛み・障害）

| # | 痛み | 深刻度 |
|---|------|--------|
| 1 | **開発コストが高い** - 独自開発すると数百万円かかる | 高 |
| 2 | **導入期間が長い** - 開発に数ヶ月かかり、タイムリーな施策ができない | 高 |
| 3 | **マンネリ化** - 同じようなキャンペーンでユーザーが飽きる | 高 |
| 4 | **ブロック率上昇** - エンゲージメントが低下し、配信効果が減少 | 高 |
| 5 | **データ活用不足** - 参加データを追客に活かせていない | 中 |
| 6 | **他機能との連携不足** - 抽選と会員証などが分断されている | 中 |

### Gains（期待する成果）

| # | 期待成果 | 重要度 |
|---|---------|--------|
| 1 | 最短3日で抽選キャンペーンを開始できる | 高 |
| 2 | 低コストで高品質な抽選体験を提供できる | 高 |
| 3 | ユーザーが楽しめるインタラクティブな体験を作れる | 高 |
| 4 | 参加データを自動でセグメント化し、追客配信に活用できる | 中 |
| 5 | 会員証やポイントなど他機能と連携できる | 中 |
| 6 | キャンペーン効果を定量的に測定・報告できる | 中 |

## バリューマップ（Value Map）

### Products & Services（提供する製品・サービス）

| カテゴリ | サービス内容 |
|---------|-------------|
| **デジタル抽選機能** | スピードくじ、ガチャ、スロット等の多彩な抽選体験 |
| **顧客セグメント自動化** | 行動データに基づく自動タグ付け |
| **LIFF/ID連携** | 既存LINE公式アカウントとのシームレスな統合 |
| **他機能連携** | 会員証機能、セグメント配信との連携 |
| **ログインボーナス** | 毎日のアクセス習慣を形成するガチャ機能 |
| **デジタルスタンプラリー** | 回遊促進と抽選を組み合わせた体験 |

### Pain Relievers（痛みの解消）

| 痛み | 解消方法 |
|------|---------|
| 開発コストが高い | 低コストで導入可能なパッケージ提供 |
| 導入期間が長い | 最短3日での導入を実現 |
| マンネリ化 | スピードくじ、ガチャ、スロット等の多彩な演出 |
| ブロック率上昇 | ワクワクする抽選体験でエンゲージメント向上 |
| データ活用不足 | 自動セグメント化による追客配信の実現 |
| 他機能との連携不足 | 会員証・ポイント・配信機能との統合 |

### Gain Creators（成果の実現）

| 期待成果 | 実現方法 |
|---------|---------|
| 最短3日で開始 | 標準化されたテンプレートと導入プロセス |
| 低コスト導入 | 開発済み機能のカスタマイズで提供 |
| インタラクティブ体験 | Framer Motionによるリッチなアニメーション |
| 自動セグメント化 | 参加行動に基づく自動タグ付け機能 |
| 他機能連携 | LIFF/ID連携による統合アーキテクチャ |
| 効果測定 | ダッシュボードによる参加率・当選率分析 |

## まとめ

### 主要な価値提案

1. **スピード**: 最短3日で抽選キャンペーンを開始
2. **コスト削減**: 独自開発と比較して大幅なコスト削減
3. **エンゲージメント**: 多彩な抽選演出でユーザーを楽しませる
4. **データ活用**: 自動セグメント化で追客配信を実現
5. **拡張性**: 会員証・ポイント・配信など他機能と連携
