# 狩野モデル - グロースパック for LINE 抽選機能

## 概要

機能の優先順位付けに使用。MVPでは「当たり前品質」の確保と1つの「魅力的品質」に集中する。

---

## 品質分類マトリクス

```
        満足度
          ↑
          │          ★ 魅力的品質
          │         /  （リッチなガチャ演出）
          │        /
          │       /
          │      /
          │     /    ─── 一元的品質
          │    /    /   （処理速度、レスポンス）
          │   /    /
          │  /    /
          │ /    /
          │/    /
──────────┼───────────────────→ 充足度
         /│   /
        / │  /
       /  │ /
      /   │/
     /    │
    /     │
   /      │─── 当たり前品質
          │    （ログイン機能、エラーがないこと）
          │
          ↓
```

## 機能分類

### 当たり前品質（Must-be Quality）

**定義**: ないと不満、あっても満足度が上がらない。MVPで**必須**。

| # | 機能 | 説明 | MVP |
|---|------|------|-----|
| 1 | LINE認証 | LINEログインでスムーズに認証できる | ✅ |
| 2 | 抽選実行 | ボタンタップで抽選が確実に実行される | ✅ |
| 3 | 結果表示 | 当選/ハズレの結果が正しく表示される | ✅ |
| 4 | クーポン表示 | 当選したクーポンが正しく表示される | ✅ |
| 5 | エラーハンドリング | エラー時に適切なメッセージが表示される | ✅ |
| 6 | ローディング表示 | 処理中に適切なローディングが表示される | ✅ |
| 7 | レスポンシブ対応 | スマホ画面で正しく表示される | ✅ |

### 一元的品質（Performance Quality）

**定義**: あればあるほど満足度が上がる。MVPでは**選択的**に実装。

| # | 機能 | 説明 | MVP |
|---|------|------|-----|
| 1 | 処理速度 | 抽選結果が素早く表示される | ✅ |
| 2 | 抽選演出のバリエーション | 複数の演出から選択できる | ✅（3種類） |
| 3 | 景品のバリエーション | 複数の景品等級を設定できる | △ |
| 4 | 参加回数管理 | 1日1回、期間中1回などの制限 | △ |
| 5 | 参加履歴 | 過去の参加・当選履歴を確認 | ❌ |
| 6 | 当選確率表示 | 景品ごとの当選確率を表示 | ❌ |

### 魅力的品質（Attractive Quality）

**定義**: なくても不満はないが、あると感動。MVPでは**1つに集中**。

| # | 機能 | 説明 | MVP | 選定 |
|---|------|------|-----|------|
| 1 | **リッチなガチャ演出** | アニメーションとサウンドで没入感のある体験 | ✅ | **採用** |
| 2 | スロット演出 | カジノ風のスロットアニメーション | ✅ | 追加採用 |
| 3 | スピードくじ演出 | めくるアニメーションのくじ引き | ✅ | 追加採用 |
| 4 | 紙吹雪エフェクト | 当選時の派手な演出 | ✅ | 付随 |
| 5 | SNSシェア | 当選結果をSNSでシェア | ❌ | - |
| 6 | ログインボーナス | 毎日参加でボーナス | ❌ | - |
| 7 | スタンプラリー連携 | スタンプ収集で抽選権獲得 | ❌ | - |

## MVP機能決定

### MVP必須機能（当たり前品質 + 1つの魅力的品質）

```
┌─────────────────────────────────────────────────────────────┐
│                        MVP スコープ                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【当たり前品質】必須実装                                     │
│  ├── LINE認証（LIFFログイン）                                │
│  ├── 抽選実行（ボタンタップで実行）                          │
│  ├── 結果表示（当選/ハズレ画面）                             │
│  ├── クーポン表示（当選景品の表示）                          │
│  ├── エラーハンドリング                                      │
│  ├── ローディング表示                                        │
│  └── レスポンシブ対応                                        │
│                                                             │
│  【一元的品質】選択実装                                       │
│  ├── 処理速度の最適化                                        │
│  └── 抽選演出3種類（スピードくじ、ガチャ、スロット）          │
│                                                             │
│  【魅力的品質】1つに集中 → 3種の演出を魅力的品質として採用    │
│  └── リッチなアニメーション演出                              │
│      ├── ガチャ演出（カプセル排出アニメーション）            │
│      ├── スロット演出（リール回転アニメーション）            │
│      ├── スピードくじ演出（カードめくりアニメーション）      │
│      └── 当選時エフェクト（紙吹雪、光の演出）                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### MVP対象外機能

| 機能 | 理由 | 将来リリース |
|------|------|-------------|
| SNSシェア | コア体験ではない | Phase 2 |
| 参加履歴 | マイページ機能が必要 | Phase 2 |
| ログインボーナス | 別機能として提供 | Phase 2 |
| スタンプラリー連携 | 別機能との統合が必要 | Phase 3 |
| 当選確率表示 | 運用ポリシー次第 | オプション |

## デモで魅せるべき魅力的品質

### 選定理由

**リッチな抽選演出**を魅力的品質として選定した理由:

1. **視覚的インパクト**: デモで一目で「すごい」と思わせる
2. **差別化要因**: 競合との明確な差を示せる
3. **実装済み**: 3種類の演出（ガチャ、スロット、スピードくじ）で多彩さをアピール
4. **エンゲージメント**: ユーザーの参加意欲を高める

### デモでの見せ方

| 演出 | 見せ方 | ポイント |
|------|--------|---------|
| ガチャ | カプセルマシンからカプセルが出てくる | 色鮮やかなアニメーション |
| スロット | リールが回転して揃う | スリル感、カジノ風の演出 |
| スピードくじ | カードをめくる | シンプルだが即時性がある |
| 当選エフェクト | 紙吹雪、光の演出 | 感動を演出、達成感 |

## まとめ

MVPでは**当たり前品質を確実に実装**し、魅力的品質として**リッチな抽選演出（ガチャ・スロット・スピードくじ）**に集中することで、デモでのインパクトと実用性を両立させる。
