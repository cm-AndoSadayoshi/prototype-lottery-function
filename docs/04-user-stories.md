## ユーザーストーリー詳細

### エンドユーザー（LINE友だち）

#### 認知・誘導フェーズ

```
US-1: スピードくじに参加する
As a 店舗来店者
I want to 店頭のQRコードをスキャンして抽選に参加したい
So that お得な特典をゲットできるチャンスを得られる
```

```
US-2: LINE通知から参加する
As a LINE友だち
I want to プッシュ通知からワンタップで抽選に参加したい
So that 簡単にキャンペーンに参加できる
```

#### 参加準備フェーズ

```
US-3: LINE認証でログインする
As a 抽選参加者
I want to LINEログインでスムーズに認証したい
So that 面倒な会員登録なしで参加できる
```

```
US-4: 参加資格を確認する
As a 抽選参加者
I want to 自分の参加資格（残り回数など）を確認したい
So that いつ、何回参加できるかわかる
```

#### 抽選実行フェーズ

```
US-5: スピードくじを引く
As a 抽選参加者
I want to ボタンをタップしてくじを引きたい
So that ドキドキしながら抽選を楽しめる
```

```
US-6: ガチャを回す
As a 抽選参加者
I want to ガチャの演出を楽しみながら抽選したい
So that ゲーム感覚でワクワクしながら参加できる
```

```
US-7: スロットを回す
As a 抽選参加者
I want to スロットの演出で抽選を楽しみたい
So that カジノのようなスリルを味わえる
```

#### 結果確認フェーズ

```
US-8: 当選結果を確認する
As a 抽選参加者
I want to 当選結果と景品内容を確認したい
So that 何が当たったかすぐにわかる
```

```
US-9: ハズレ結果を確認する
As a 抽選参加者
I want to ハズレでも次回参加への動機付けを得たい
So that また参加したいと思える
```

#### 特典利用フェーズ

```
US-10: クーポンを利用する
As a 当選者
I want to 当選したクーポンを店舗で簡単に提示したい
So that スムーズに特典を受け取れる
```

```
US-11: 獲得履歴を確認する
As a 抽選参加者
I want to 過去の当選履歴を確認したい
So that 自分の獲得した特典を管理できる
```

---

### マーケティング担当者

#### キャンペーン設定

```
US-12: 抽選キャンペーンを作成する
As a マーケティング担当者
I want to 簡単に抽選キャンペーンを設定したい
So that 素早くキャンペーンを開始できる
```

```
US-13: 当選確率を設定する
As a マーケティング担当者
I want to 景品ごとの当選確率を柔軟に設定したい
So that 予算に合わせた運用ができる
```

```
US-14: 抽選演出を選択する
As a マーケティング担当者
I want to ブランドに合った抽選演出を選びたい
So that ブランドイメージに合ったキャンペーンを実施できる
```

#### 効果測定

```
US-15: 参加データを分析する
As a マーケティング担当者
I want to 抽選参加者のデータを分析したい
So that キャンペーン効果を測定できる
```

```
US-16: 追客配信を実行する
As a マーケティング担当者
I want to 参加者に対して追客メッセージを送りたい
So that 購買につなげられる
```

## MVPスコープ

### MVP対象機能

| # | 機能 | ストーリー | 優先度 |
|---|------|-----------|--------|
| 1 | LIFF起動 | US-1, US-2 | 必須 |
| 2 | LINE認証 | US-3 | 必須 |
| 3 | スピードくじ演出 | US-5 | 必須 |
| 4 | ガチャ演出 | US-6 | 必須 |
| 5 | スロット演出 | US-7 | 必須 |
| 6 | 当選画面 | US-8 | 必須 |
| 7 | ハズレ画面 | US-9 | 必須 |
| 8 | クーポン表示 | US-10 | 必須 |

### MVP対象外（将来機能）

| # | 機能 | ストーリー | 備考 |
|---|------|-----------|------|
| 1 | SNSシェア | - | エンゲージメント拡大 |
| 2 | ポイント連携 | - | 会員証機能との連携 |
| 3 | 獲得履歴 | US-11 | マイページ機能 |
| 4 | ログインボーナス | - | リピート促進 |
| 5 | スタンプラリー連携 | - | 回遊促進 |

## まとめ

MVPでは「認知→参加→抽選→結果→特典利用」のコアフローに集中し、3種類の抽選演出（スピードくじ、ガチャ、スロット）を実装。追加機能は段階的にリリースする。
