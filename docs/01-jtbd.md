# Jobs To Be Done（JTBD）- グロースパック for LINE 抽選機能

## 概要

ユーザーがLINE抽選機能を使いたくなる「文脈」と「動機」を言語化する。

---

## マーケティング担当者のJTBD

### JTBD 1: キャンペーン企画時

```
When: 新規キャンペーンを企画しているが、予算や開発リソースが限られている時
I want to: 低コストで素早く導入できる抽選キャンペーンを実施したい
So that: 開発期間を待たずにタイムリーなキャンペーンを実行できる
```

### JTBD 2: マンネリ化対策時

```
When: LINEアカウントのブロック率が上昇し、エンゲージメントが低下している時
I want to: ユーザーが楽しめるインタラクティブな体験を提供したい
So that: アカウントへの興味を維持し、ブロック率を下げられる
```

### JTBD 3: データ活用時

```
When: キャンペーン参加者のデータを有効活用したい時
I want to: 参加行動に基づいて顧客を自動的にセグメント化したい
So that: 適切な追客配信でコンバージョンを向上させられる
```

---

## エンドユーザー（LINE友だち）のJTBD

### JTBD 1: 店頭での買い物時

```
When: お気に入りのお店で買い物をしている時
I want to: 簡単に参加できる抽選でお得な特典を獲得したい
So that: 買い物がより楽しくなり、お得感を得られる
```

### JTBD 2: 施設回遊時

```
When: 商業施設やイベント会場を訪れている時
I want to: スタンプラリーと抽選を組み合わせた体験を楽しみたい
So that: 施設内を楽しく回遊しながら特典をゲットできる
```

### JTBD 3: リピート利用時

```
When: お気に入りのECサイトやアプリを日常的に利用している時
I want to: ログインボーナスやデイリーガチャで特典を得たい
So that: 毎日のアクセスが楽しみになり、お得にサービスを利用できる
```

## 業種別JTBD

### 小売・アパレル

```
When: 来店促進施策を検討している時
I want to: 店頭QRコードでスピードくじを提供したい
So that: 来店動機を創出し、購買意欲を高められる
```

### 商業施設・イベント

```
When: 施設内の回遊率を向上させたい時
I want to: デジタルスタンプラリー×抽選を実施したい
So that: 来場者が施設全体を楽しく回遊してくれる
```

### EC・Webサービス

```
When: ユーザーのリピート率を向上させたい時
I want to: ログインボーナスガチャを導入したい
So that: 毎日のアクセス習慣を形成し、LTVを向上させられる
```
